# PolkaSell - prototipo frontend

## Cómo ejecutarlo
1. Descarga y descomprime `PolkaSell.zip`.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en tu navegador (puedes usar la extensión Live Server).

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: diseño y estilos responsivos.
- `app.js`: interacciones y datos de demostración.

## Importante
Esta es una demostración frontend. Los datos se guardan en `localStorage` del navegador.
No hay cuentas reales, chat real, pagos, verificación de ventas ni conexión blockchain.
Las ofertas de subasta son simuladas. Para publicar una imagen, puedes pegar una URL pública en el campo de imagen.
